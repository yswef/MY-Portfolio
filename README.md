# Yusef Alhmzy — Portfolio v2

موقع شخصي كامل (Full-stack) مبني بـ PHP + SQLite، مع لوحة تحكم خاصة لإدارة المشاريع والرسائل ونص السيرة الذاتية — بدون لمس أي كود بعد أول رفعة.

![License](https://img.shields.io/badge/license-MIT-e8b923)
![PHP](https://img.shields.io/badge/PHP-8.1%2B-7c4dff)
![Languages](https://img.shields.io/badge/languages-5-1c1c24)

## المزايا
- تصميم عصري متجاوب بالكامل، وضع داكن/فاتح، ودعم 5 لغات (عربي، إنجليزي، إسباني، فرنسي، ياباني).
- **لوحة تحكم حقيقية** (`/admin`) محمية بتسجيل دخول: إضافة/تعديل/حذف المشاريع مع رفع صور، تعديل نص السيرة الذاتية لكل لغة، وقراءة رسائل التواصل.
- نموذج تواصل حقيقي يخزّن الرسائل في قاعدة البيانات (مع حماية Honeypot وتحديد معدّل الإرسال).
- أمان حقيقي: كلمات مرور مشفّرة (`password_hash`)، حماية CSRF على كل نموذج، Prepared Statements في كل استعلام، تحقق من نوع الصور المرفوعة فعليًا (لا الامتداد فقط)، وسياسة أمان محتوى (CSP) صارمة.

## البنية التقنية
```
index.php              الصفحة الرئيسية (PHP يجلب البيانات من القاعدة)
api/
  projects.php          JSON: قائمة المشاريع المنشورة (?lang=ar|en|es|fr|ja)
  bio.php                JSON: نص "عني" حسب اللغة
  contact.php            استقبال نموذج التواصل
admin/                  لوحة التحكم (محمية بتسجيل دخول)
includes/                طبقة قاعدة البيانات + المصادقة + أدوات مشتركة
data/portfolio.sqlite   قاعدة البيانات (تُنشأ تلقائيًا، محمية من الوصول المباشر)
css/ js/ assets/         الواجهة الأمامية
translations/            نصوص الواجهة الثابتة (القوائم، الأزرار...) لكل لغة
setup.php                إنشاء حساب المدير الأول — يُحذف بعد الاستخدام
```

## التشغيل محليًا
يتطلب PHP 8.1+ مع امتدادي `sqlite3` و`gd`:
```bash
php -S localhost:8000
```
ثم افتح `http://localhost:8000/setup.php` لإنشاء حساب المدير الأول.
